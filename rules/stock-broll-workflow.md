# Stock B-roll workflow

When editing talking-head / gesture / short-form videos, do not wait for the user to hand-pick stock clips. Run this loop yourself:

1. **Plan from picture** — Watch/read the source; list needed B-roll by beat (mood, metaphor, transition, detail insert). Prefer face-safe overlays: top band / lower half / cutaways that do not cover the face.
2. **Search** — Prefer [Pexels Videos](https://www.pexels.com/videos/). Use ChatCut/Pireel library stock only as a supplement when already in-project.
3. **Download & organize** — Save under a clear local folder (e.g. `outputs/broll-<slug>/`) with a short `MANIFEST.md` mapping each clip to timeline beats.
4. **Cut in** — Import, place, grade to match A-roll, keep creative MGs/SFX in safe zones; verify with timeline frames before calling done.

Skip heavy B-roll only when the piece is pure motion/gesture and inserts would hurt clarity—still note that choice briefly.
