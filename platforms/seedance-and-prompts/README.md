# Seedance & creative prompts

Official **prompt and creative** packs for Seedance / 即梦 and related video models.

Part of cutmax **platforms** — included to make generated films better, not to replace local editing.

| Skill | Focus |
|---|---|
| `seedance` | Seedance 2.0 中文提示词核心 |
| `seedance2` | （上级目录）创意工作台，含 API 生成 |
| `seedance-prompt-en` | English (+ zh) prompting |
| `seedance-shot-design` | 分镜 / 运镜 / 导演风格 |
| `seedance-viral-hook` | 开头钩子 |
| `seedance-ai-avatar` | AI 数字人口播 |
| `seedance-before-after` | 前后对比 |
| `seedance-course-promo` | 课程推广 |
| `seedance-faceless-channel` | 无出镜频道 |
| `seedance-luxury-aesthetic` | 奢侈美学 |
| `seedance-personal-brand` | 个人品牌 |
| `seedance-podcast-visual` | 播客可视化 |
| `seedance-saas-launch` | SaaS 发布 |
| `seedance-testimonial-story` | 客户证言 |
| `vibe-creating-prompt` | 跨模型 vibe 改写 |
| `fpv-immersive-video-prompting` | FPV / 路线控制 |

Enable via `./scripts/link-platforms.sh`.
